## Edit notes

- Hard cuts or short dissolves; keep pace up  
- Captions: bold white + muted subline (same system as screenshots)  
- Safe zones: avoid top 8% and bottom 12% for critical text  
- **Show:** real import → live retune → privacy line  
- **Hide:** crashes, debug banners, empty library, competitor brands  
- Prefer a **short public-domain or original** tone; silence is OK
