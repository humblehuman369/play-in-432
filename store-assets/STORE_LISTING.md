## What only you can do (accounts)

1. Enroll **Apple Developer** + create app in App Store Connect  
2. Enroll **Google Play Console** + create app  
3. In Xcode: select Team → Archive → Upload  
4. In Android Studio: Generate signed **AAB** → Play Console  
5. Attach screenshots (run Simulator yourself if device list is empty)  
6. Submit for review
