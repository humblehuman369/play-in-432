# Google Play upload pack — Play In 432

Everything you need for the first Android release. **You** paste into Play Console and submit.

## Start here

1. Open **[PLAY_CONSOLE_FILL_SHEET.md](./PLAY_CONSOLE_FILL_SHEET.md)** (every field answered).  
2. Open this folder in Finder and [Play Console](https://play.google.com/console).  
3. Upload **`play-in-432-1.1.0-vc11.aab`**, paste text, attach graphics.  
4. Prefer **Internal testing** first, then **Production → Send for review**.
